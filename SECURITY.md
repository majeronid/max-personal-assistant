# Security Policy

Max Personal Assistant is a private, account-owner-only assistant project.

## Secret handling

Do not commit Twilio tokens, messaging-service SIDs in reusable examples, phone-number exports, OAuth refresh tokens, `.env` files, browser cookies, or logs containing personal messages.

## Messaging safety

The public pages in this repo describe private SMS compliance language only. The assistant must not be repurposed for marketing, patient messaging, lead generation, public outreach, or bulk SMS without a separate compliance review.

## Reporting

Report non-sensitive issues through private GitHub issues. Escalate credentials, payment, legal, account-security, or PHI-adjacent concerns directly to David.
